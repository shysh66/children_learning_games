# משחקי החשבון שלי 🎮
## Children's Math Learning Games

**גרסה נוכחית:** 1.1.0 | **עודכן:** 26.01.2025

אפליקציית React אינטראקטיבית ללימוד מתמטיקה לילדים עם 3 נושאים מגניבים!

> 📝 לשינויים מפורטים בין גרסאות, ראה [CHANGELOG.md](CHANGELOG.md)

### 🌟 תכונות
- 🚀 נושא חלל
- 🦕 נושא דינוזאורים  
- 🦄 נושא חדי-קרן
- ✖️ לוח כפל
- ➕➖ חיבור וחיסור
- 🎉 אנימציות וקונפטי
- 📊 מעקב התקדמות

### 🚀 התקנה והרצה מקומית

```bash
# התקנת dependencies
npm install

# הרצה בסביבת development
npm start

# בניה לproduction
npm run build
```

### 📦 Deploy ל-Vercel (מומלץ! 🚀)

**הכי פשוט וקל:**

1. התחבר ל-Vercel עם GitHub: https://vercel.com/signup
2. ייבא את הrepo הזה
3. לחץ Deploy
4. זהו! האתר live + deploy אוטומטי לכל push

**מדריך מפורט:** ראה [VERCEL_DEPLOYMENT.md](VERCEL_DEPLOYMENT.md)

---

### 📦 Deploy ל-GitHub Pages (חלופה)

```bash
# התקן gh-pages
npm install --save-dev gh-pages

# הוסף לpackage.json scripts:
"predeploy": "npm run build",
"deploy": "gh-pages -d build"

# Deploy
npm run deploy
```

**מדריך מפורט:** ראה [DEPLOYMENT.md](DEPLOYMENT.md)
